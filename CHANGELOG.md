# Changelog

## 2.0.0

- Require Obsidian 1.13.0 or later and adopt searchable declarative settings.
- Add sentence and paragraph focus levels.
- Add a persisted enable setting and a **Toggle focus** command with `Command+D`/`Ctrl+D` as its default hotkey.
- Avoid treating periods inside decimal numbers, URLs, and file paths as sentence endings.
- Replace private Obsidian globals and prototype extensions with supported APIs.
- Refresh the TypeScript, CodeMirror, build, lint, and release toolchain.
- Add clean release artifacts, generated release notes, and artifact attestations.
- Document installation, usage, privacy, development, and contribution workflows.
